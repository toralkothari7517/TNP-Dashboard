# TNP Dashboard

A clean placement and internship tracking dashboard that displays job application deadlines and past interview questions synced from a Google Sheet, with a manual CSV fallback.

## Features
- **Dashboard**: Track upcoming and urgent application deadlines with countdowns.
- **Sync**: Pull data directly from a Google Sheet using the Sheets API.
- **Interview Bank**: View and search interview questions by company.
- **CSV Fallback**: Import data manually via CSV if the Sheets API is not configured.
